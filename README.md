# Cure the Hollow — Legal

Privacy policy and terms of use for games published by Cure the Hollow.

Hosted via GitHub Pages.

## URLs (after Pages is enabled)

- `https://<your-org>.github.io/<repo-name>/` — landing page
- `https://<your-org>.github.io/<repo-name>/privacy.html` — privacy policy
- `https://<your-org>.github.io/<repo-name>/terms.html` — terms of use

## Updating

1. Edit the relevant `.html` file.
2. Bump the "Last updated" date at the top of the file.
3. Commit and push — GitHub Pages re-deploys automatically.
